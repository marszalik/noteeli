# Welcome to Noteeli 👋

This is the **public demo** of Noteeli — a Markdown-first web workspace
inspired by Obsidian. You can browse, read, and click around the file
tree, but **no changes are saved**. Reload the page and the demo is
back to its initial state.

## What to try

- 📁 **File tree** on the left — full folder hierarchy, type-aware icons
- 📝 **WYSIWYG Markdown editor** (toggle to **Markdown** to see the source)
- 🎨 **Themes** — pick one in *Settings → Appearance* (Webnote.li,
  Noteeli, Obsidian, Light, Dark)
- ✨ **Markdown styles** — *Settings → Editor → Markdown rendering style*
  — five distinct "skins" for the same content
- 🌐 **5 UI languages** — English, Polski, Español, Deutsch, Русский
- 🧩 **Mermaid** and **PlantUML** diagrams — see `examples/Diagrams.md`
- 🎼 **Syntax-highlighted code** — see `projects/snippets.py`
- 📊 **JSON, docx, xlsx, pptx** — every Office file gets a read-only
  preview

## Three-step tour

1. Click **`Welcome.md`** in the tree — this is the document you're
   reading now
2. Open **Settings ⚙** in the top-right corner — play with themes
3. Browse `examples/` for a longer showcase

> **Demo mode** = read-only. To write your own notes on your own disk
> (or via SFTP / Google Drive), [download Noteeli](https://noteeli.com).
